# shertwg · GamejamCyberhand

Подготовка команды к геймджему «Моторика: Код движения», 30.10.2026.

«Маяк: Последний свет» — офлайн-игра о ремонте корабля на Керне. Игрок восстанавливает отсеки, выращивает еду, добывает материалы за обшивкой и готовит корабль к взлёту. Ремонтные задания принимают команды A/B через общий адаптер. Экранная панель позволяет попробовать их сразу.

## Старт

1. Открой корневой `project.godot` в Godot **4.4.1** и запусти игру через **F5**. Первый запуск начинается с кат-сцены.
2. Тап по полу двигает рейнджера. В ремонте нажми «Продолжить», затем используй экранные A/B. Метка ◆ указывает ближайший шаг по сюжету, а «Карта» показывает цель.
3. Android preset `Android Debug APK` экспортирует отладочную сборку в `builds/android/shertwg-debug.apk`; каталог `builds/` не попадёт в Git.
4. Путь к JDK/SDK задаётся в локальных настройках Godot каждого компьютера и не сохраняется в репозитории.
5. Август принимает изменения по `planning/repository.md`, коммитит и интегрирует небольшими порциями.

## Навигация

- `planning/product.md` — продукт, MVP и выигрышная демонстрация.
- `planning/tasks.md` — владельцы, сроки, зависимости и приёмка.
- `planning/assignments.md` — полные карточки задач всей команды.
- `planning/team/` — отдельные карточки Августа, Антона, Димы, Арины и Алисы.
- `planning/AI_PROJECT_CONTEXT.md` — общий бриф и правила для AI-помощников.
- `planning/repository.md` — репозиторий, ветки и интеграция.
- `planning/requirements.md` — подтверждённые сведения и пробелы.
- `contracts/input-v1.schema.json` — внутренний формат входного кадра.
- `contracts/README.md` — взаимодействие модулей и метрики.
- `qa/manual-cases.md` — сценарии проверки на телефоне.
- `evidence/` — журналы проверок, ИИ и источников ассетов.

Участники начинают с карточки в `planning/team/` и общего брифа `planning/AI_PROJECT_CONTEXT.md`.
