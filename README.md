Это локальная копия https://github.com/shertwg/GamejamCyberhand с подготовленными организационными и техническими файлами. Репозиторий клонирован после открытия публичного доступа; на момент клонирования он был пустым. Добавленные файлы ещё не закоммичены и не отправлены. Полное ТЗ раздела «Задачи» ещё требуется получить. Готовой игры здесь пока нет.

## Старт

1. Август сверяет `planning/requirements.md` с полным ТЗ, проверяет допуск всех пяти участников.
2. Просматривает подготовленные файлы через git status и редактор. В этом checkout файлы уже размещены.
3. Команда принимает концепцию из `planning/product.md`; предварительный стек — Godot **4.4.1**, GDScript, 2D, Android. Проект под Аврору остаётся отдельным.
4. Август выполняет первый коммит самостоятельно. Затем из checkout запускает `tools/setup-local-branches.ps1`. Скрипт создаёт только отсутствующие локальные ветки от `main`, не переключает рабочую ветку и ничего не отправляет.
5. Настраивает GitHub по `planning/repository.md`. Шаблон CODEOWNERS пока не действует: нужен реальный логин капитана.
6. Сегодня закрываем A01, A02, N01, D01, R01, L01 из `planning/tasks.md`.

## Навигация

- `planning/product.md` — продукт, MVP и выигрышная демонстрация.
- `planning/tasks.md` — владельцы, сроки, зависимости и приёмка.
- `planning/repository.md` — репозиторий, ветки и интеграция.
- `planning/requirements.md` — подтверждённые сведения и пробелы.
- `contracts/input-v1.schema.json` — внутренний формат входного кадра.
- `contracts/README.md` — взаимодействие модулей и метрики.
- `qa/manual-cases.md` — сценарии проверки на телефоне.
- `evidence/` — журналы проверок, ИИ и источников ассетов.

Папки будущего проекта: `game/core` — Август; `game/ui` — Антон; `game/gameplay` — Дима; `game/content` — Арина через Августа; `qa` — Алиса. Файла `project.godot` здесь намеренно нет: сначала сверяемся с существующим репозиторием и проверяем Android-экспорт на 4.4.1.
