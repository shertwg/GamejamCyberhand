# Изюминка миссий — концепт для Августа

09.11.2026. Только обсуждение; новых механик в коде нет.

## Буря: компенсируемый снос

В `repair-2` добавить слабый вертикальный ветер: A поднимает против сноса,
B опускает. Начать с постоянного направления и заметной индикации вектора;
без случайных разворотов и без дополнительного управления.
Кандидат для первого прогона — 0.03 высоты поля в секунду, около 6% базовой
вертикальной скорости 0.48. На лёгком шаге уменьшать ветер, на сложном
не усиливать одновременно ветер, скорость и сужение прохода.

Снос работает только при разрешённой OPEN/CLOSE с intensity > 0.
REST, BOTH, восстановление ввода, пауза и потеря фокуса останавливают и дрон,
и время ветра. Коллизии проходят существующие подшаги Course.
Не штрафовать отдых. Проверить, хватает ли обеим командам скорости для
компенсации при малой аналоговой интенсивности; при необходимости масштабировать снос.
Сначала оставить удержание метрикой; обязательное непрерывное удержание обсуждать отдельно.

## Ядовитый воздух: движущаяся заслонка

В `repair-3` сначала добавить одну медленную заслонку между существующими
переборками. Показывать рельс, направление и крайние положения; цикл задавать
активным игровым временем, чтобы REST замораживал препятствие.
Перед ним оставить безопасное место для остановки и гарантированный проход
для коллайдера дрона с запасом. Касание мягко блокирует движение, без внезапной смерти.

Для первого прогона сохранить статический просвет не уже базового 0.35;
не складывать новую ловушку сразу с максимальным сужением адаптации.
Автоматически проверить весь цикл заслонки на шагах −1/0/+1 и при низком FPS,
затем проверить читаемость и нагрузку на одну руку на телефоне.

Обе механики размещаются в Course, получают только ControlCommand и не меняют
контракт ввода. Реализацию и новые параметры LevelConfig согласовать с Августом.

## Варианты уровней и тренажёров — 10.11.2026

Это идеи для обсуждения, не реализованные функции. «Тренажёр» здесь означает
игровую практику управления двумя сигналами, а не медицинскую программу.
Физическую нагрузку и перенос навыков на протез эта игра пока не подтверждает.

### Главная миссия: «Сердце корабля» — миниреактор «Искра-7»

Рейнджер собирает компактный источник энергии из деталей аварийного корабля.
Сначала на столе лежит тёмный металлический корпус; после каждого действия
появляются катушки, кольца и светящиеся дорожки. В финале реактор помещается
в нагрудный модуль ремонтного экзокостюма и включает обесточенные отсеки.
Настроение — инженерная мастерская и эффектный запуск в духе Тони Старка;
название, устройство, силуэт и сюжет делаем своими.

| Этап | Действие игрока | Интерес и обратная связь |
|---|---|---|
| 1. Корпус | Провести оболочку через широкий монтажный проём | Знакомая механика Course; мягкая первая победа |
| 2. Магнитные кольца | Совместить по одному кольцу с контуром посадочного места | A/B смещают деталь по одной оси; правильная посадка даёт щелчок и свет |
| 3. Катушка | Направлять контакт по широкой дорожке намотки | Несколько коротких участков вместо одного длинного зажима; виден собранный виток |
| 4. Стабилизатор | Удерживать указатель в зоне настройки | A повышает параметр, B понижает; плавный гул и ровное свечение показывают устойчивость |
| 5. Защитный кожух | Закрыть сегменты, попадая в отмеченные положения | Умеренная точность, каждый сегмент сохраняет прогресс |
| 6. Первый запуск | Вывести мощность в рабочую зону и завершить короткую стабилизацию | Свет расходится по кораблю, Маяк оживает, открывается новый отсек |

В MVP сначала сделать этапы «корпус → кольца → запуск»; катушку и кожух добавить
при наличии времени. Это один запоминающийся уровень с тремя короткими сценами,
а не шесть новых систем сразу. На каждом этапе работает одна управляемая величина.
Переходы и установка детали автоматические после успеха; третья кнопка не нужна.
Спокойный REST замораживает процесс, а авария возвращает только текущую деталь.

### Другие сюжетные уровни

| Уровень | Что делаем | Что практикуем | Награда в мире |
|---|---|---|---|
| «Пульс Маяка» | Собрать новый привод повреждённой руки робота-напарника | A/B по очереди, различение команды и покоя | Робот впервые машет игроку восстановленной рукой |
| «Холодный запуск» | Поставить клапан и отрегулировать подачу хладагента | Переключения каналов и подвод к целевой зоне | Пар исчезает, перегретый отсек становится синим |
| «Магнитный замок» | Совместить магнитную каретку с тремя контактами шлюза | Короткие корректировки и остановки между целями | Открывается мастерская с миниреактором |
| «Хирургия корабля» | Провести ремонтный контакт по треснувшей силовой дорожке | Плавное движение, точность у поворотов | Дорожка загорается позади инструмента; промах гасит только текущий участок |
| «Пыльный генератор» | Провести энергоячейку через отсек с боковым сносом | Компенсация возмущения и смена направления | Вращается генератор, включается свет жилого блока |
| «Герметичный контур» | Совместить заплатки с утечками на корпусе | Подвод и стабилизация на нескольких коротких целях | Исчезает токсичный туман, высаживается зелёный росток |
| «Орбитальная антенна» | По очереди настроить азимут и высоту сигнального отражателя | Контроль одной оси и точная доводка | В небе появляется ответный спасательный сигнал |
| «Первый шаг титана» | Пройти предстартовую настройку ремонтного экзокостюма | Повтор A/B, покой, выход из BOTH, затем небольшой маршрут | Рейнджер надевает собранный модуль и выходит на поверхность |

Для поворотных механизмов A/B предлагаются как две противоположные команды
текущего узла. Это требует согласования отображения OPEN/CLOSE и подсказок;
не переименовывать контракт ввода внутри отдельных сцен. Азимут и высота
настраиваются последовательно, без требования одновременно управлять двумя осями.

### Короткие тренажёры в мастерской

| Тренажёр, один раунд 30–60 секунд | Правило | Как сделать интересным |
|---|---|---|
| «Сортировщик лома» | Подводить каретку к подсвеченному контейнеру | Из собранного металла на глазах появляется полезная деталь |
| «Ювелирная пайка» | Остановить контакт на нескольких широких, затем более узких площадках | На плате постепенно складывается рисунок созвездия |
| «Магнитный балансир» | Держать каретку около центра при заранее показанном возмущении | В центре левитирует маленькая светящаяся сфера |
| «Катушка индуктора» | Выполнить несколько чередований A → нейтраль → B | Каждый завершённый цикл добавляет видимый виток, без требования частого спама |
| «Тихий привод» | Чередовать движение и явный покой в обозначенных местах | На остановке исчезает дрожь инструмента; Маяк даёт короткую подсказку |
| «Ремонт после сбоя» | Намеренный BOTH, затем оба канала в нейтраль и одна команда | Учимся безопасному восстановлению на учебном узле без штрафа |

Ограничение 30–60 секунд — ориентир длительности активных игровых фрагментов,
а не обязанность непрерывно подавать сигнал. REST и системные паузы не уменьшают
награду и не расходуют время задания. Встречный сигнал в учебном раунде не считать ошибкой.
Награды — детали и визуальные улучшения корабля; рейтинг по силе сигнала не нужен.

### Порядок прототипирования

1. «Пульс Маяка» — пошаговое обучение и эмоциональный ответ персонажа.
2. «Сердце корабля» — главный демонстрационный уровень из трёх этапов.
3. «Ювелирная пайка» и «Катушка индуктора» — короткие повторяемые задания
   на тех же узлах, без новых типов ввода.
4. Ветер и движущиеся заслонки — после проверки базовых режимов на устройстве.

До реализации стабилизации определить, что считается успехом: сохранение положения,
ненулевая активность или нахождение сигнала в целевом диапазоне. Текущая бинарная
панель не даёт дозировать интенсивность. Не строить обязательную цель на слабом
аналоговом сигнале, пока у игрока нет поддерживающего его источника ввода.
