# Изюминка миссий — концепт для Августа

09.11.2026. Только обсуждение; новых механик в коде нет.

## Буря: компенсируемый снос

В `repair-2` добавить слабый вертикальный ветер: A поднимает против сноса,
B опускает. Начать с постоянного направления и заметной индикации вектора;
без случайных разворотов и без дополнительного управления.
Кандидат для первого прогона — 0.03 высоты поля в секунду, около 6% базовой
вертикальной скорости 0.48. На лёгком шаге уменьшать ветер, на сложном
не усиливать одновременно ветер, скорость и сужение прохода.

Снос работает только при разрешённой OPEN/CLOSE с intensity > 0.
REST, BOTH, восстановление ввода, пауза и потеря фокуса останавливают и дрон,
и время ветра. Коллизии проходят существующие подшаги Course.
Не штрафовать отдых. Проверить, хватает ли обеим командам скорости для
компенсации при малой аналоговой интенсивности; при необходимости масштабировать снос.
Сначала оставить удержание метрикой; обязательное непрерывное удержание обсуждать отдельно.

## Ядовитый воздух: движущаяся заслонка

В `repair-3` сначала добавить одну медленную заслонку между существующими
переборками. Показывать рельс, направление и крайние положения; цикл задавать
активным игровым временем, чтобы REST замораживал препятствие.
Перед ним оставить безопасное место для остановки и гарантированный проход
для коллайдера дрона с запасом. Касание мягко блокирует движение, без внезапной смерти.

Для первого прогона сохранить статический просвет не уже базового 0.35;
не складывать новую ловушку сразу с максимальным сужением адаптации.
Автоматически проверить весь цикл заслонки на шагах −1/0/+1 и при низком FPS,
затем проверить читаемость и нагрузку на одну руку на телефоне.

Обе механики размещаются в Course, получают только ControlCommand и не меняют
контракт ввода. Реализацию и новые параметры LevelConfig согласовать с Августом.
