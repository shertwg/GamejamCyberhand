# Антон — карточка UI shertwg

**Ветка:** `feat/anton-ui`  
**Зона:** только `game/ui/`. Объём сопоставим с задачей Димы.

Перед началом прочитай `AGENTS.md`, `planning/AI_PROJECT_CONTEXT.md` и `contracts/README.md`.

## Задачи

1. **Навигационный каркас (P0).** Собери последовательные экраны: старт, выбор стороны/настроек, объяснение калибровки и эмулятора, tutorial, игровая оболочка/пауза, результат и повтор. На первом этапе можно использовать демонстрационные данные. Путь должен быть проходимым и не иметь тупиков.
2. **Панель двух каналов (P0).** Показывай два аналоговых значения 0..1, пороговые отметки, активное направление и интенсивность. Сенсорные элементы эмулятора меняют только тестовый `InputSource` через согласованный сигнал/метод, не двигают захват напрямую. Режим явно подписан «Эмулятор».
3. **Понятные состояния (P0).** Сделай текстовую/визуальную подсказку для REST, OPEN, CLOSE, BOTH, обрыва/устаревшего сигнала, успеха и промаха. Не сообщай смысл только цветом. Крупные кнопки, читаемый текст, зеркальное размещение под выбранную руку.
4. **Пауза и результат (P0).** UI отправляет только команды навигации/паузы/повтора и отображает `SessionSummary`; не владеет игровой логикой, таймерами уровня или метриками.
5. **Обратная связь сложности (P1).** Объясняй игроку, когда изменился темп/окно, и почему. Убедись, что адаптация видна, но интерфейс не обещает медицинский эффект.
6. **Мобильная проверка (P1).** Проверь минимум два размера/соотношения экрана, устрани обрезанный текст и элементы в собственной зоне. Передай Августу список сигналов/методов навигации и инструкцию подключения UI к корневой сцене.

## Не делать

Не менять `project.godot`, корневую сцену/autoload, `contracts/`, `game/core/` и `game/gameplay/`; не читать сенсор/клавиатуру напрямую для игры; не делать самостоятельный commit/push/merge.

## Приёмка

Экраны собираются как отдельные сцены, маршрут проходим на заглушках. Значения каналов, пороги и команда видимы; нажатия UI не подменяют игровой вход. Запиши фактические проверки и передай файлы/инструкцию Августу.
