# Дима — карточка gameplay shertwg

**Ветка:** `feat/dima-gameplay`  
**Зона:** только `game/gameplay/`. Объём сопоставим с UI Антона.

Перед началом прочитай `AGENTS.md`, `planning/AI_PROJECT_CONTEXT.md`, `contracts/README.md` и `contracts/examples/input-frame.json`.

## Задачи

1. **Игровая сцена (P0).** Создай компактную 2D-сцену станции: автоматический рельсовый маршрут магнитного захвата, одна деталь, ремонтный слот. Механика сразу должна читаться без кат-сцены и длинного текста.
2. **Управление через контракт (P0).** Игровой модуль принимает `ControlCommand` Августа: REST/OPEN/CLOSE/BOTH плюс intensity 0..1. Интенсивность пропорционально меняет скорость открытия/закрытия. Никакого чтения UI, клавиатуры, касаний или аппаратуры из игровой сцены. Временно тестируй локальными командами/заглушкой, явно пометь их временными.
3. **События (P0).** Выдавай игровые события начала/успеха/ошибки/завершения с причиной и ID попытки, чтобы ядро считало итоги. UI не вызывай напрямую и общий контракт не меняй.
4. **Tutorial (P0).** Коротко обучи открыть, закрыть, отпустить/вернуться в покой и понять реакцию на BOTH.
5. **Три разных уровня (P0).** 1) большие детали, широкое окно; 2) удержать/перенести/отпустить; 3) небольшие детали и точная установка. Уровни должны отличаться навыком/параметрами, не только фоном; конфигурации храни отдельно от сцены.
6. **Адаптация (P0).** Реализуй ограниченное правило: несколько последовательных успехов немного ускоряют маршрут/сужают окно, серия ошибок замедляет/расширяет его. Изменяй постепенно, объяснимо и с нижней/верхней границами. Передай конкретные параметры Антону для пояснения и Августу для интеграции.
7. **Пауза/повтор и обратная связь (P1).** Пауза останавливает таймер и игровое движение; повтор сбрасывает текущую попытку. Добавь ясные эффекты захвата, переноса и восстановления секции станции.

## Не делать

Не менять UI, корень, `project.godot`, `contracts/`, core или игровые тексты Арины; не добавлять новые мини-игры до приёмки P0; не делать commit/push/merge.

## Приёмка

Игровую сцену можно отдельно пройти тестовыми командами; интенсивность видимо влияет на действие; все состояния и события корректны; tutorial, уровни, адаптация, пауза и повтор работают. Передай Августу список сцен/параметров/сигналов и точные шаги воспроизведения.
