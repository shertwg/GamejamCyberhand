# Баланс миссий — 09.11.2026

## 1. Конфиг прогрессии

В `game/content/missions.json` подготовлены параметры:

| Миссия | off | on | Разрыв on − off | width | duration, с |
|---|---:|---:|---:|---:|---:|
| Обучение | 0.35 | 0.60 | 0.25 | 0.48 | 10 |
| Жара | 0.40 | 0.55 | 0.15 | 0.40 | 12 |
| Буря | 0.42 | 0.54 | 0.12 | 0.36 | 18 |
| Ядовитый воздух | 0.45 | 0.50 | 0.05 | 0.35 | 20 |

Обучение получает широкий гистерезис, Жара сохраняет базовые параметры,
Буря — промежуточный разрыв и увеличение duration с 16 до 18 секунд,
финал — узкий гистерезис для менее терпимого к колебаниям сигнала управления.
Ширины маршрутов сохранены: 0.48 → 0.40 → 0.36 → 0.35.

Это **конфиг для подключения**, а не уже изменившаяся игра. Поиск ссылок и
запуск координатора подтвердили: `missions.json` сейчас не читается игрой.
Геометрия и цели удержания берутся из `game/core/level_config.gd`, пороги —
из профиля `LocalStore`. В запущенном tutorial on остаётся 0.55, при JSON on=0.60.
Кроме того, сенсорная панель отправляет только 0/1: при таких сигналах смена
порогов сама по себе не меняет движение. Нужен отдельный прогон аналоговых трасс.

Разрыв off/on — гистерезис, а не диапазон, внутри которого надо держать сигнал.
Внутри него декодер сохраняет направление, но intensity равна нулю.
Широкий разрыв уменьшает переключения состояния, однако on=0.60 требует
более высокого сигнала для начала движения. Удобство этого выбора ещё не проверено игроком.

`duration` не задаёт непрерывное удержание. В текущем runtime цели удержания:
800 / 1200 / 1600 / 2000 мс; Буря уже имеет более долгую цель, чем Жара.
`Course` завершает миссию при достижении шлюза даже без выполнения этой цели:
удержание пока является метрикой. Увеличение JSON duration не включает новое условие победы.

## 2. Проверка адаптации

`session_coordinator.gd::_finish_progress()` вызывает
`LevelConfig.evaluate_adaptation()`; сама функция находится в `game/core/level_config.gd`.
Изолированный запуск реального координатора дал:

| Сценарий, исходный шаг 0 | Шаги после попыток |
|---|---|
| Три повтора без завершения | 0, 0, 0; struggle_streak=0 |
| Три завершения одной миссии без BOTH | 0, +1, +1 |
| Три завершения с unwanted_both_ms ≥ 1000 каждое | 0, −1, −1 |
| Чистое обучение, затем первый чистый ремонт Жары | tutorial=0, repair-1=+1 |
| Два чистых завершения при отключённой адаптации | 0, 0 |

В игре пока нет состояния проигрыша. Столкновение блокирует движение,
таймаут поражения отсутствует. Повтор незавершённой миссии не вызывает
`_finish_progress()`, поэтому «три проигрыша → легче» сейчас не реализовано.
Даже медленный ремонт без BOTH считается чистым. Серии общие для всех миссий:
чистое обучение может повысить сложность уже после первого завершения Жары.
Новые параметры применяются при следующем запуске миссии, не посреди маршрута.

Все 4 маршрута пройдены алгоритмом на шагах −1/0/+1. Минимальный проход:

| Миссия | −1 | 0 | +1 |
|---|---:|---:|---:|
| Обучение | 0.48 | 0.48 | 0.48 |
| Жара | 0.44 | 0.40 | 0.36 |
| Буря | 0.40 | 0.36 | 0.32 |
| Ядовитый воздух | 0.39 | 0.35 | 0.32 |

Высота коллайдера дрона — 0.09; минимальный запас перемещения его центра —
0.23 высоты поля. Ограничитель высоты стены 0.68 не даёт просвету стать уже 0.32.
Геометрической непроходимости не обнаружено. Это проверка алгоритмом с полной
интенсивностью, она не доказывает удобство управления пальцем или аналоговым сигналом.

### Дополнительная проверка аналогового сигнала — 09.11.2026

По уточнению пользователя продолжается только проверка баланса. Ядро и JSON
не менялись. Поскольку JSON пока не подключён, его пороги явно передавались
в отдельный настоящий `InputPipeline`, затем его команды — в `Course`.
Геометрия и цели удержания брались из текущего `LevelConfig`. Это моделирование
будущего подключения порогов, а не тест уже интегрированной версии игры.

Проверены 48 сочетаний: 4 миссии × 3 шага адаптации × сигналы 0.58/0.65/0.80/1.00.
Из них 45 пройдены; в трёх вариантах tutorial сигнал 0.58 ожидаемо ниже on=0.60
и не запускает движение. Все 88 проверок поведения завершились без ошибок.
Это подтверждение наблюдаемого поведения, а не заключение об удачном балансе.

| Миссия, шаг 0 | intensity при сигнале 0.65 | Время маршрута, с | При сигнале 0.58 |
|---|---:|---:|---|
| Обучение | 0.1250 | 74.15 | Нет движения |
| Жара | 0.2222 | 46.60 | 155.35 с |
| Буря | 0.2391 | 43.30 | 119.10 с |
| Ядовитый воздух | 0.3000 | 33.35 | 62.50 с |

Контроллер выбирал A/B для обхода ближайшей стены; канал подавался с указанной
силой, другой — с нулём, кадр каждые 50 мс. Это идеальное переключение алгоритмом,
без реакции человека, пауз и ошибок. Удержание в зоне не было целью контроллера.

Выводы для следующего согласования с Августом:

- Широкий гистерезис обучения сочетается с наиболее высоким порогом включения:
  на умеренном сигнале обучение существенно медленнее остальных миссий.
  Поэтому текущие JSON-пороги пока нельзя считать подтверждённой плавной прогрессией.
  Кандидат для отдельного сравнения: одинаковый on=0.55, off=0.30/0.40/0.43/0.50
  по порядку миссий. Разрывы сохранятся 0.25/0.15/0.12/0.05, а преобразование силы
  сигнала в скорость станет одинаковым. Этот кандидат пока не применён и не прогнан.
- После активации сигнал 0.49 сохраняет ACTIVE с intensity=0 во всех четырёх
  профилях. За 10 секунд дрон не смещается, но Course и SessionTracker учитывают
  10 секунд активности. REST при нулевом сигнале замораживает и движение, и время.
- Если начать эту проверку внутри hold_zone, SessionTracker даёт 100% удержания
  при нулевой intensity. Сейчас метрика означает нахождение в зоне при ACTIVE,
  а не непрерывное ненулевое усилие. Нужно согласовать, какое из этих действий
  должна требовать будущая механика; стационарное удержание само по себе не ошибка.
- На шаге 0 при полном сигнале Буря завершилась с 1100/1600 мс нахождения в зоне,
  финал — с 500/2000 мс. Это конкретные примеры финиша без достижения цели удержания;
  они не доказывают невозможность выполнить её при другой стратегии.
- Для каждого JSON-профиля проверено восстановление BOTH → удержанный канал
  (WAITING_NEUTRAL) → оба канала ровно на off (REST) → противоположный канал (ACTIVE).
  Различие порогов не нарушило этот сценарий восстановления.

Результаты сохранены в `evidence/gameplay-analog-20261109.json`.
Локальный скрипт: `work/analog_balance_probe.gd` (игнорируется Git);
