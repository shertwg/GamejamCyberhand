# Правила работы над GamejamCyberhand

- Целевая версия Godot: 4.4.1. Не обновлять движок, не менять настройки другого проекта под Аврору.
- До получения полного ТЗ решения в planning/product.md считаются предложением команды, а не требованиями организаторов.
- Работать только в зоне назначенной задачи. Общие файлы project.godot, export_presets.cfg, contracts/, корневая сцена и autoload принадлежат Августу.
- Коммиты, push, merge, теги и релизы выполняет Август. Агент подготавливает изменения и результат проверок; не выполняет эти действия без отдельного поручения капитана.
- Не запускать несколько агентов на одних файлах. Делегировать задачи агентам только по прямому указанию пользователя.
- UI не читает клавиши и сенсор напрямую для игровой механики. Источник ввода проходит через адаптер и общий контракт.
- Основной игровой сценарий должен работать офлайн. Не добавлять сервер, аккаунты, LLM API и распознавание ЭМГ без согласования scope с Августом.
- ИИ-изменения фиксировать в evidence/ai-log.csv. Не объявлять проверку успешной без фактического запуска.
- Не включать ключи подписи, пароли, данные пациентов и чужие ассеты с неизвестными условиями. Источники компонентов и ассетов записывать в evidence/assets.csv.
- Не обещать медицинскую эффективность: проверки на эмуляторе подтверждают работу программы, а не перенос навыков на реальный протез.
- В отчёте о задаче: изменённые файлы, поведение, выполненные проверки, ограничения, инструкция для Августа по интеграции.
