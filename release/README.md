# Android · Маяк / Последний свет

Скачайте [kerna-android.apk](kerna-android.apk) на телефон, откройте файл и запустите установленную игру. Версия 0.9.0-rc1 подписана отладочным ключом и поддерживает ARM64 и x86_64. Требуется OpenGL ES 3.0. Игра работает офлайн.

Управление и проверенные сценарии описаны в [инструкции](../submission/README.md) и [отчёте о проверках](../submission/verification.md).
