# Ручная проверка APK

Это план, не отчёт о пройденных проверках. В evidence/test-runs.csv записывать дату, сборку/commit, телефон, ОС, кейс, ожидание, факт, статус и ссылку на доказательство. Статусы: NOT_RUN, PASS, FAIL, BLOCKED. Сейчас все кейсы NOT_RUN.

| ID | Шаги | Ожидаемый результат |
|---|---|---|
| Q01 | Установить APK на чистый телефон, запустить офлайн | Приложение открывается и даёт начать без аккаунта |
| Q02 | Пройти tutorial впервые без устных подсказок команды | Объяснены открытие, закрытие, покой и встречный сигнал; можно повторить |
| Q03 | Поочерёдно включить A, B, оба, отпустить оба | Видны четыре состояния; действие соответствует контракту |
| Q04 | Подать трассу дрожания возле порога | Нет частых ложных переключений; проверить по журналу состояний |
| Q05 | Менять пороги отдельно, переключить зеркальное расположение | Меняется нужный канал; интерфейс доступен для обеих рук |
| Q06 | Пройти все три сложности | Все доступны по правилам прогрессии, различаются требования, есть итог |
| Q07 | Пауза 10 секунд, продолжение, повтор | Пауза не портит время/счёт; повтор не переносит события старой попытки |
| Q08 | Прервать поток, прислать невалидный/устаревший кадр | Нет залипания захвата; понятное состояние, корректное восстановление |
| Q09 | Свернуть/вернуть приложение; выключить экран | Нет неконтролируемого действия и скачка таймера; требуется явное продолжение |
| Q10 | Завершить уровень, закрыть/открыть приложение | Настройки и принятый прогресс сохраняются |
| Q11 | Нулевая попытка, дубли события, отсутствующая метрика | Нет NaN, деления на ноль и двойного начисления |
| Q12 | Проверить два размера экрана, длинные тексты и зеркальный режим | Кнопки/подсказки не перекрыты; информация не передаётся только цветом |
| Q13 | Играть 10 минут, повторять уровни | Нет падений, блокировок и неудерживаемого роста задержки |
| Q14 | Измерить задержку кадр→эффект на телефоне | Есть метод, число измерений, p50/p95, устройство; сравнить с целью команды |
| Q15 | Открыть инструкцию и запустить сдаваемый APK по ней | Инструкция достаточна, версия видео/сборки/исходников совпадает |

Для повреждённого сохранения капитан готовит тестовую копию профиля: приложение должно восстановиться без падения. Пользовательские данные не удалять ради теста. Положительные и отрицательные трассы декодера/метрик позже должны получить автоматические проверки.
